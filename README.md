## 📖 Overview
**Job Portal** is a comprehensive web application designed to bridge the gap between job seekers and recruiters. It features a responsive user interface for browsing job listings, managing profiles, and facilitating the application process.

The platform focuses on usability, clean design, and efficient data handling to create a seamless hiring experience.

## ✨ Key Features

### 👤 For Job Seekers
* **Advanced Search:** Filter jobs by category, location, and salary range.
* **User Dashboard:** Manage profile details, resume uploads, and applied jobs.
* **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
* **Instant Apply:** One-click application submission.

### 🏢 For Recruiters / Admin
* **Job Management:** Post, edit, and delete job vacancies.
* **Application Tracking:** View and manage incoming applications.
* **Company Profiles:** Create and update company details.

## 🛠️ Tech Stack

### Backend
* **Framework:** Flask (Python Microframework)
* **Database:** SQLAlchemy (ORM)
* **Authentication:** Flask-Login
* **Security:** Werkzeug Security (Password Hashing)

### Frontend
* **Templating:** Jinja2
* **Styling:** Bootstrap 5 / Custom CSS
* **Scripting:** JavaScript (ES6+)

## 🚀 Installation & Setup

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/Tarun-Kannadas/Job_Portal.git](https://github.com/Tarun-Kannadas/Job_Portal.git)
    ```

2.  **Navigate to the project directory**
    ```bash
    cd Job_Portal
    ```

3.  **Setup Database (If applicable)**
    * Import the `database.sql` file provided in the `/db` folder.
    * Configure database connection settings in `config.php` (or your env file).

4.  **Run the Application**
    * Open `index.html` in your browser (for static versions) OR
    * Start your local server (e.g., XAMPP for PHP or `npm start` for Node).
